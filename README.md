# Babel（巴别塔）

Babel 是一套信息传输与协作表达规范，帮助 Agent 在不过度压缩、也不过度展开的前提下，准确传递完成当前任务所需的信息。

## 仓库内容

- [`SKILL.md`](SKILL.md)：Skill 定义与完整规范。
- [`references/explanation-calibration.md`](references/explanation-calibration.md)：解释范围与深度的校准参考。
- [`references/collaboration-hygiene.md`](references/collaboration-hygiene.md)：多步骤协作中的沟通参考。
